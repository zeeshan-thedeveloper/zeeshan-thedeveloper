## 🧭 How I Think as an Engineer

- **Product-first.** The feature only matters if it works for the user and the business.
- **Clean architecture.** Boring, predictable boundaries beat clever abstractions every time.
- **Maintainability over novelty.** Code is read more than it is written; I optimize for the reader.
- **Real workflows, not demos.** I care about the messy parts — auth, edge cases, retries, observability.
- **Ship, then iterate.** A small thing in production teaches more than a big thing on a branch.
